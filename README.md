# Rotovedras TV

A app das TVs das fábricas da Rotovedras (Fire TV): abre o painel da Gestão de Produção em ecrã inteiro.

**Instalar:** na Fire TV, app Downloader, endereço `gestao-producao.rotovedras.pt/apk`.

Versão 1.2 (compilação 3). Este repositório só guarda o ficheiro para descarregar; é atualizado automaticamente.
